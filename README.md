# Maura Diamonds
Static single-page site for lab-grown diamonds, WhatsApp-enquiry based.

- Set the client's number in `index.html` → `WHATSAPP_NUMBER` (country code, digits only).
- Add photos to `images/` and place `<img>` tags inside each `.ph` block (see comments).
- Host anywhere static: GitHub Pages, Netlify, Vercel.
