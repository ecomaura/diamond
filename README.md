# Maison Aura — Lab-Grown Diamond Jewellery (static site)
Enquiry-only luxury catalogue; WhatsApp is the conversion path (no cart/checkout).
- Set your number in `js/app.js` → `CONFIG.whatsapp` (digits with country code).
- Images: every `.ph` placeholder takes `data-img="images/your-file.jpg"`.
- Pages: `index.html`, `collection.html?c=<slug>`, `product.html?c=<slug>&p=<id>`, `contact.html`.
- Edit collections/products in the `COLLS` array in `js/app.js`.
