# Ecomaura

A bespoke, responsive luxury lab-grown diamond jewellery catalogue and WhatsApp enquiry experience.

## Setup
- Static website. Open `index.html` locally or deploy the repository with GitHub Pages.
- No cart, checkout, online payment or buy-now functionality.
- Update `WHATSAPP_NUMBER` in `js/app.js` with the brand's WhatsApp number (country code + number, digits only; no plus sign).
- Replace editorial photography and sample catalogue entries with approved brand/product assets and specifications before launch.

## Pages
- Homepage with brand philosophy, collections, craftsmanship, lab-grown diamond education and bespoke enquiry.
- Collection detail views via hash routes (for example `#collection/engagement`).
- Product enquiry actions create product-specific WhatsApp messages.

## Notes
All product names and specifications shown in collection views are editorial examples pending the brand's approved catalogue.
