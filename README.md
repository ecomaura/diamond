# Maura Diamonds
Static single-page site for lab-grown diamonds, WhatsApp-enquiry based.

- Set the client's number in `index.html` → `WHATSAPP_NUMBER` (country code, digits only).
- Edit pieces in the `ITEMS` list. Drop photos into `images/` named `<id>.jpg` (e.g. `images/oval-halo.jpg`); they replace the placeholders automatically.
- Visitors can add several pieces and send one combined WhatsApp enquiry.
- Host anywhere static: GitHub Pages, Netlify, Vercel.
